제외는 `a9731b5` 에서 했고 공개된 것은 **42커밋 전체**여서, 익명화 전 내용이 네 커밋에 그대로 남아 있었다:

| 커밋 | 무엇 |
|---|---|
| `9816246` 슬라이스 5 — 회차 기록 반입 | 익명화 전 회차 기록이 처음 들어온 커밋 |
| `9bcb944` 포트 고정 | 실제 홈 경로(사용자명)·GitHub 계정이 든 증거 노트 |
| `44475c3` 슬라이스 10 | 같은 계열 |
| `a9731b5` 제외 커밋 | **지운 내용이 diff 로 남는다** |

`git log -S` 로 확인한 노출 범위: 개인 이름 4커밋 · 가족 맥락 4 · GitHub 계정 4 · 외부 사이트명 3 ·
업체명 3 · 실제 프로젝트명 2 · 실제 홈 경로 2. **API 키·토큰은 히스토리 전체에 0건**이었다
(`.env`·`*.local.json` 은 한 번도 커밋되지 않았다). fork·star·watcher 는 0, 공개 창은 수 분이었다.

**조치.** ① 즉시 비공개로 되돌렸다. ② 지금 트리만 담은 **단일 커밋**으로 히스토리를 다시 세웠다
(`c449e12`). ③ 옛 히스토리는 로컬 브랜치 `history-do-not-push` 로만 남기고 원격 추적을 끊었다.
④ 저장소를 삭제하고 **같은 이름으로 다시 만들어** 새 히스토리를 올린다 — force-push 는 GitHub 서버에
지워진 개씨를 SHA 로 남기고 커밋 뷰가 캐시될 수 있어 고르지 않았다.

**재생성한 히스토리를 다시 검사했다**: 개인 이름·가족 맥락·계정·외부 사이트명·업체명·실제 프로젝트명·
홈 경로 **전부 0건**, 키·토큰 0건, `§4` 0건. 이 과정에서 **내가 쓴 노트 두 개가 새로 걸렸다** —
검수 노트가 검수 대상 문구를 예시로 인용했고(가족 거주지 표현), 배포 노트에 옛 GitHub 계정이 있었다.
둘 다 고쳤다. **검수 문서 자체가 누출 경로가 된다.**
